# Face Lens — 顔検出AI

カメラまたは写真から、顔の位置と6つの特徴点を検出するブラウザアプリ。顔検出であり、個人の識別・本人認証は行いません。

## 使い方

HTTPSで公開されたページをSafariやChromeで開き、「カメラを起動」を押してカメラを許可してください。「写真を選ぶ」では端末内の画像を検出します。

- カメラ停止、特徴点の表示切替、カメラの左右反転に対応。
- ページが非表示になるとカメラを停止します。
- 映像・写真のサーバー送信、保存、解析ログの保存は行いません。
- 初回にjsDelivrからMediaPipe Tasks Vision 0.10.32のJavaScript/WASMと、GoogleからBlazeFaceモデルを読み込みます。外部配信先には通常のリクエスト情報が送信されます。
- AIモデルの読込にネット接続が必要です。APIキーや有料APIは使いません。

## 開発

このフォルダで `python3 -m http.server 8080` を実行し、同じ端末の `http://localhost:8080` で開けます。別端末からカメラを利用する場合はHTTPSが必要です。ビルド不要のHTML/CSS/JavaScriptです。

構文確認: `node --check app.js`

## 確認項目

1. 顔のあるJPG/PNGを選び、顔の枠、特徴点、人数が表示される。
2. 顔のない画像では0人になる。
3. カメラ許可後に顔が追従する。停止すると端末の使用表示が消える。
4. 左右反転時に枠と特徴点が映像に重なる。
5. 特徴点の表示切替、ページ移動後のカメラ停止を確認する。
6. カメラ拒否、モデル読込失敗時にエラー表示され、再試行できる。

精度は照明、距離、横向き、遮蔽によって変わります。本人確認などには使用しないでください。
